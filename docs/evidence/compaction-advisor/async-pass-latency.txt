The 3.0s substituted summarization call stands in for the 20-50s a real
summarization of a large context takes (measured on the live session that
motivated snapcompact's no-LLM contract). The INLINE arm is the pre-change
call site reproduced exactly: plan, then await _run_compaction. The ASYNC arm
is the shipped path driven through the real _on_turn_end hook.

The apply boundary costs ~0.001-0.005s because the expensive half is already done:
all that remains is rebuilding the message list, which is why the pass can
land on a live turn without the user noticing it.
