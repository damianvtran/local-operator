cli.exec_remote_help.budget_usd | Spending cap for this run in US dollars (default: the server's admission default) | 本次运行的花费上限，单位为美元（默认：服务器的准入默认值）
cli.exec_remote_help.cancel | Cancel a remote run and exit | 取消一次远程运行并退出
cli.exec_remote_help.detach | Print the run id and idempotency key, then exit instead of watching the run | 打印运行ID和幂等键后退出，而不是监视该运行
cli.exec_remote_help.idempotency_key | Idempotency key to reuse instead of minting a fresh one, so a retry of a submitted run cannot run twice | 复用此幂等键而不生成新键，使已提交运行的重试不会运行两次
cli.exec_remote_help.max_hours | Hours the remote run may execute before the server stops it (default: 2; the server caps the maximum) | 远程运行在服务器停止它之前可执行的小时数（默认：2；最大值由服务器限制）
cli.exec_remote_help.network | Network to submit the run through, by name or id. Required when this device is in more than one network | 提交运行所用的网络，按名称或ID指定。本设备位于多个网络时必须指定
cli.exec_remote_help.remote | Run this task on Radient remote compute (tier 1: short-lived runs) instead of this machine | 在Radient远程计算上运行此任务（第1档：短时运行），而非在本机运行
cli.exec_remote_help.repo | Git URL the remote run checks out. Required with --remote: local files are never uploaded | 远程运行检出的Git URL。配合--remote时必填：本地文件从不上传
cli.exec_remote_help.sha | Commit to check out in --repo. Required with --remote | 在--repo中检出的提交。配合--remote时必填
cli.exec_remote_help.size | Compute size for the remote run: s, m or l (default: m) | 远程运行的计算规格：s、m或l（默认：m）
cli.exec_remote_help.status | Print one remote run as JSON and exit | 以JSON打印一次远程运行并退出
