cli.config_help.instructions_description	Show which custom-instruction files a session assembles, in order, with the size each contributed and whether it was collapsed as a duplicate, truncated, or overlaps an earlier source. Paths and sizes only, never the contents.	按顺序显示会话组装的自定义指令文件，包括各文件贡献的大小，以及是否因重复而折叠、被截断或与之前的来源重叠。仅显示路径和大小，不显示内容。
