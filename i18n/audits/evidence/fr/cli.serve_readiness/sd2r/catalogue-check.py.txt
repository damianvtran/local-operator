 'ES-SD1-01':'señales de actividad naturally conveys heartbeat/liveness signals in Spanish, avoiding the literal loan. It preserves no response and cessation of reporting, not proof that the process died.',

 'RU-SD1-02':'не может распознать expresses inability of this check to recognize/classify the cgroup rather than determine its spatial position. It does not assert absent cgroup membership or known unsupervised execution.',
 'RU-SD1-03':'The respectful выполните instruction keeps exact status/restart commands and order. просмотреть записи and записать идентификационные данные процессов are natural in this technical context; данные is explicitly about processes, not user credentials. перед перезапуском команда проверяет keeps the command as checking actor and places per-daemon checks before restart; no unconditional restart or guaranteed identity recovery is promised.',
 'VI-SD1-01':'chưa phân loại được unambiguously means the check has not been able to classify the cgroup, replacing spatial vị trí. It retains uncertainty and developer-register cgroup without inventing a known supervisor or missing group.',
 'HI-SD1-01':'श्रेणी ... पता नहीं चल पा रही है states that the check cannot determine the category. It replaces spatial स्थान, remains idiomatic standard Hindi and does not infer absent supervision.',
 'UR-SD1-M1':'نوعیت ... متعین نہیں کر سکتی means this check cannot determine the nature/type. It removes spatial جگہ and preserves uncertainty. cgroup stays Latin in logical order; no manual bidi controls are introduced.',
 'ZH-SD1-01':'无法判定 ... cgroup的归属 describes uncertain cgroup ownership/classification, not inability to locate a path. 所在cgroup preserves membership context; it does not assert unsupervised execution or change the surrounding unknown verdict.'}
COUNTS=[0,1,2,3,4,5,11,21,22,25,1.5,1000000,1500000]
CATEGORIES={'fr':{'one','many','other'},'es':{'one','many','other'},
            'ru':{'one','few','many','other'},'vi':{'other'},
            'hi':{'one','other'},'ur':{'one','other'},'zh-CN':{'other'}}
BIDI=set('\u061c\u200e\u200f\u202a\u202b\u202c\u202d\u202e\u2066\u2067\u2068\u2069')
def sha(p): return hashlib.sha256(p.read_bytes()).hexdigest()
def rel(p): return str(p.relative_to(ROOT))
def read(p): return json.loads(p.read_text(encoding='utf-8'))
def put(p,text):
 p.parent.mkdir(parents=True,exist_ok=True)
 with p.open('x',encoding='utf-8') as f: f.write(text)
def dump(p,obj): put(p,json.dumps(obj,ensure_ascii=False,indent=2)+'\n')
NOW=datetime.datetime.now(datetime.timezone.utc).isoformat()
HEAD=subprocess.check_output(['git','rev-parse','HEAD'],text=True).strip()
SOURCE=CAT/'en'/(NS+'.json'); CONTEXT=CAT/'en'/(NS+'.context.json')
en=read(SOURCE); context=read(CONTEXT)
assert len(en)==11 and set(en)==set(context)
paths=[SOURCE,CONTEXT,ROOT/'i18n/glossary.md']
paths += [CAT/l/(NS+'.json') for l in LOCALES]
paths += [ROOT/'i18n/style-guides'/(l+'.md') for l in LOCALES]
paths += [BASE/l/NS/'sd2'/n for l in LOCALES for n in ['record.json','report.md','rendered.txt','receipt.json']]
initial={rel(p):sha(p) for p in paths}
provenance={'agent':'Local Operator — second independent i18n auditor (sd2r)',
 'session':'85af124f4a9f','model':'openai/gpt-6.1-sol',
 'actual_model_source':'Host session declaration; same resumed independent auditor session as sd2.',
 'fallback':'none observed or reported',
 'independence':'Not translator acf0a84cd992 and not any first-pass auditor. No translation contribution or changes authored by this auditor. Fresh target semantics independently reviewed before reading sd1 finding IDs/suggestions; historical sd2 clean status does not override sd1 findings.',
 'native_speaker_claim':False,'round':'second-pass remediation'}
logs=[f'$ python3 -B {rel(COMMON/"catalogue-check.py.txt")}',f'cwd={ROOT}',

results=[]
for locale in LOCALES:
 directory=BASE/locale/NS/'sd2r'
 prior_dir=BASE/locale/NS/'sd2'
 prior=read(prior_dir/'record.json')
 for name,path in [('en',SOURCE),('context',CONTEXT)]:
  assert sha(path)==prior['input_hashes'][name],(locale,name,'changed source/context')
 for p in [ROOT/'i18n/glossary.md',ROOT/'i18n/style-guides'/(locale+'.md')]:
  assert sha(p)==prior['supporting_input_hashes'][rel(p)],(locale,'style/glossary changed')
 # Existing sd2 receipts must remain byte-valid, never rewritten.
 for name,digest in read(prior_dir/'receipt.json')['sha256'].items():
  assert sha(prior_dir/name)==digest,(locale,'prior receipt',name)
 target_path=CAT/locale/(NS+'.json'); target=read(target_path)
 assert len(target)==11 and set(target)==set(en)
 # Recover the ORIGINAL values of the nine nonplural changed keys from the
 # actual sd2 runtime text, undo only those replacements in a copy in memory,
 # and require byte SHA equality with the complete original target catalogue.
 # This binds all remaining 68 values AND JSON formatting without trusting a
 # translator claim, a current Git base or a narrow diff excerpt.
 old_rendered=(prior_dir/'rendered.txt').read_text(encoding='utf-8')
 reconstructed=dict(target); delta=[]
 for short in CHANGES[locale]:
  key=NS+'.'+short
  marker=f'## {key} | count=1 | CLDR=n/a\n\n'
  assert old_rendered.count(marker)==1
  old=old_rendered.split(marker,1)[1].split('\n',1)[0]
  if short=='identity_restart': old=old.replace('host-sd2','{device}')
  assert old!=target[key],(locale,key,'no actual change')
  reconstructed[key]=old
  delta.append({'key':key,'before':old,'after':target[key]})
 reconstructed_bytes=(json.dumps(reconstructed,ensure_ascii=False,indent=2)+'\n').encode('utf-8')
 assert hashlib.sha256(reconstructed_bytes).hexdigest()==prior['input_hashes']['target'],(locale,'unexpected bytes beyond declared remediation')
 assert target_path.read_bytes()==(json.dumps(target,ensure_ascii=False,indent=2)+'\n').encode('utf-8')
 logs.append(f'PASS {locale}: reconstructed full prior target SHA256={prior["input_hashes"]["target"]}; changed keys={CHANGES[locale]}; remaining {11-len(delta)} values and formatting unchanged')
 rendered=[f'# sd2r rendered catalogue text — {locale}',
 'Offline production ICU runtime with explicit locale; not service execution or a screenshot.','']
 seen=set(); renders=0; pseudo=0
 for key,text in target.items():
  assert runtime.message_arguments(en[key])==runtime.message_arguments(text),(locale,key,'argument order/kind')
  assert not any(c in BIDI or unicodedata.category(c)=='Cc' for c in text)
  if locale=='vi': assert unicodedata.normalize('NFC',text)==text
  plurals=runtime.plural_selectors(text)
  for selectors in plurals: assert set(selectors)==CATEGORIES[locale]
  literals=set(re.findall(r'`([^`]+)`',en[key]))
  assert literals==set(re.findall(r'`([^`]+)`',text))
  for node in runtime.parse_message(text):
   if getattr(node,'kind',None)=='plural':
    expected={n for n,k in runtime.message_arguments(en[key]) if k!='plural'}
    for selector,body in node.parts:
     assert {n.name for n in body if hasattr(n,'name')}==expected
     branch_literals=set()
     for n in body:
      if hasattr(n,'value'): branch_literals.update(re.findall(r'`([^`]+)`',n.value))
     assert branch_literals==literals
  for count in (COUNTS if plurals else [1]):
   params={'count':count,'device':'host-sd2r','pids':'4101, 4102','holders':'worker.service',
           'builds':'v0.99.1+running','recorded':'v0.99.0+recorded','install':'v0.99.2+installed'}
   # Direct neighbor composition uses CURRENT remediated reasons, not an
   # unrelated old reason. This also checks the uncertainty wrapper at all counts.
   params['reasons']='pid 4101: '+runtime.render_message(target[NS+'.not_reporting'],{},locale)+'; pid 4102: '+runtime.render_message(target[NS+'.cgroup_unknown'],{},locale)

   for name,kind in runtime.message_arguments(text):

   category=plural_category(locale,count) if plurals else 'n/a'
